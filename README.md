# 鼠标轨迹连点器

这是一个 Windows 桌面鼠标录制与回放工具。它会在整个桌面范围内记录鼠标移动、左/右/中键、双击、滚轮和拖动，并按录制时的绝对坐标与事件间隔回放。

## 环境要求

- Windows 10/11
- Python 3.8 或更高版本
- 桌面环境可用 Tkinter

## 安装与启动

在项目目录运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

如果电脑上有多个 Python 版本，请使用同一个 Python 解释器执行安装和启动，例如：

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

## 使用方法

1. 点击“新建”，创建并命名一套模板。
2. 选中模板，点击“开始录制”。倒计时 3 秒后，在其他软件中执行鼠标操作。
3. 完成后回到连点器窗口，点击“停止录制”。程序以点击停止的时刻为终点，自动忽略最后 3 秒的录制内容，再保存模板。
4. 设置固定循环次数，或勾选“无限循环”。
5. 点击“开始回放”。程序先倒计时 5 秒，倒计时期间不会操作鼠标；需要取消时点击“停止”，倒计时结束后才开始回放。回放过程中可使用“暂停/继续/停止”。
6. 可以创建多套模板并随时切换、重命名或删除。

录制和回放只通过窗口按钮控制，不使用全局快捷键。连点器自己的窗口区域会从录制数据中排除，避免把控制按钮录进去。

## 模板位置

模板保存在：

```text
%APPDATA%\MouseClicker\templates
```

每套模板是一个版本化 JSON 文件，只保存在本机。

## 坐标与安全提示

- 回放使用绝对屏幕坐标，适合固定的分辨率、缩放比例和显示器布局。
- 程序启动时启用每显示器 DPI 感知，录制和回放统一使用物理屏幕像素，避免 Windows 缩放导致坐标按比例偏移。
- 如果桌面布局发生变化，回放前会提醒确认。
- 旧版本录制的模板可能保存了缩放前的屏幕尺寸，升级后第一次回放可能出现布局变化提示；建议重新录制一次以更新模板屏幕信息。
- 录制不足 3 秒时，末尾裁剪后会得到空模板，需要重新录制更长的操作。
- 停止回放时，程序会释放仍处于按下状态的鼠标按钮。
- 回放开始前固定等待 5 秒，倒计时期间不会注入鼠标事件。
- 第一版只录制鼠标，不录制键盘。
- 自动化动作可能在目标软件中执行实际操作，回放前请确认当前前台窗口和模板内容。

## 打包 exe

运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成文件：`dist\MouseClicker.exe`。
